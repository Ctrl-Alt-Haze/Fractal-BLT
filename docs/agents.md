# 🧠 Agentic Configuration

Fractal-BLT acts as a localized Hive-Mind. It relies on 4 distinct agents orchestrated by the `HiveMindOrchestrator`.

## 1. The Router
The Router intercepts all user inputs and SDK queries. It hits the **Zero-Allocation HNSW Graph** (AVX2 SIMD-accelerated) to retrieve RAG contexts in under `2.4µs`.

## 2. The Coder
The primary synthesizer. It hot-swaps into the 6GB VRAM partition via PagedAttention and streams tokens at ultra-high TPS using Phase 4's NativeAOT Speculative Decoding (`FindArgMaxSimd`).

## 3. The Critic
The security supervisor. The Critic audits the `VramFragmentationScore` continuously. It ensures zero PagedAttention block fragmentation. Under OZTAE, it verifies air-gapped filesystem boundaries and cryptographically hashes tool executions to the SQLite ledger.

## 4. The Tool-Forger
The native compiler. It accepts C# scripts generated by the Coder and runs `NativeLibrary.Load()` to JIT compile unmanaged native bindings directly in-memory.
