ARCHITECTURE Q&A

HOW FAST IS THE GPUDIRECT DMA PIPELINE?
The built-in ModelHarvester natively bit-packs gigabyte Safetensors (e.g., 988 MB FP16 models) into custom 1.58-bit ternary formats. Our tests routinely blast 116 MB of quantized Safetensors directly from NVMe to VRAM in precisely 34 milliseconds, completely bypassing the CPU host memory bounce.
IS THIS A REAL LLAMA TRANSFORMER?
Yes. Phase 18 introduced a complete, zero-allocation C# NativeAOT implementation of the Llama block. It supports Rotary Positional Embeddings (RoPE), RMSNorm, Multi-Head Self-Attention, and SwiGLU MLP pathways, mapping input bytes deterministically to PTX CUDA kernels without triggering the Garbage Collector.
